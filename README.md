# ICMAP Smart Tutor Portal
Responsive PWA for laptop, desktop and mobile. Tutor capabilities are derived only from the Tutor portion of Tuto-Jarvis: AI tutoring, study plans, MCQs, numerical practice, typed-answer tests, flashcards, bilingual voice, reading workflow, progress tracking and exam preparation.

## Server secrets
Set OPENROUTER_API_KEY. Optional: OPENROUTER_MODEL, YOUTUBE_API_KEY, APP_URL.
Study-material files are stored locally in the browser for this first release; a Google Drive link can be saved as a source and opened from the portal.
